# Sunrise Image

**현재 GitHub 소스 기준: R02** · Windows 10/11 x64 · 문서 이미지 추출·변환 도구

HWPX, PDF, Word, Excel, PowerPoint 문서에 포함된 이미지를 확인하고 원하는 형식·해상도·용량으로 추출하는 Sunrise Group의 Windows 데스크톱 프로그램입니다.

## 1. 프로그램 개요
Sunrise Image는 문서 내부의 이미지 목록을 확인하고 필요한 이미지만 추출하거나 변환할 수 있는 업무지원 도구입니다. 문서를 하나씩 열어 이미지를 복사하는 반복 작업을 줄이고, 원본 이미지 품질과 문서 내 위치를 검토하면서 결과를 저장하도록 설계되었습니다.

현재 공개 저장소는 **R02 기준 소스 및 실행·빌드에 필요한 파일 중심**으로 구성되어 있습니다. 이 R02는 소스 기준 표기이며, 별도의 `vX.Y.Z` 공식 공개 릴리즈 번호가 확인된 것은 아닙니다.

## 2. 개발 목적
- 여러 업무 문서에 포함된 이미지를 한 번에 탐색·추출합니다.
- 이미지 원본의 상태, 크기와 추출 결과를 비교·확인합니다.
- 보고서·인쇄·문서 경량화 등 목적에 맞게 이미지 형식과 품질을 조정합니다.
- 필요한 이미지만 선택하고 결과를 일관된 파일 형식으로 저장합니다.
- 원본 문서를 보존하면서 별도 결과물을 생성합니다.

## 3. 주요 기능
- HWPX, PDF, DOCX, XLSX, PPTX의 내장 이미지 검색
- 문서별 이미지 목록, 미리보기와 개별 선택
- 여러 문서의 이미지 일괄 추출
- 원본 형식 추출 및 JPG·PNG·WebP·TIFF 등의 변환
- 해상도·DPI·크기·품질·용량 설정
- 원본과 변환 결과를 확인하는 미리보기
- HWPX 본문에 지정된 이미지 자르기 영역 반영
- 보고서용 JPG, 문서 용량 줄이기, 인쇄용 PNG 등의 작업 프리셋
- 작업 진행상태·완료 결과 및 결과 폴더 확인

**지원하지 않는 형식:** 구형 바이너리 한글 `.hwp`는 이미지 추출 대상이 아닙니다. 필요한 경우 지원되는 `.hwpx` 등으로 저장하여 사용하세요.

## 4. 실행조건
| 항목 | 조건 |
| --- | --- |
| 운영체제 | Windows 10 또는 Windows 11 |
| 시스템 | 64비트(x64) |
| 실행형 패키지 | `SunriseImage.exe`를 포함한 폴더형 배포본(준비된 경우) |
| 소스 실행 | 64비트 Python 및 `requirements.txt` 의존성 설치 |
| 주요 런타임 라이브러리 | PySide6, Pillow, PyMuPDF, defusedxml |
| 문서 형식 | HWPX, PDF, DOCX, XLSX, PPTX |
| 한컴 설치 | HWPX 문서 내 이미지 추출 자체에는 한컴 자동화가 필요하지 않음 |

## 5. 설치 및 사용방법
### 완성된 실행형 패키지가 있는 경우
1. 배포받은 프로그램 폴더 전체를 압축 해제합니다.
2. 폴더에 포함된 `SunriseImage.exe`를 실행합니다.
3. **문서 추가**로 추출할 문서 파일을 선택합니다.
4. 문서·이미지 목록과 미리보기에서 추출 대상을 확인합니다.
5. 출력 형식, DPI, 품질·크기 등 필요한 설정을 조정합니다.
6. 추출 작업을 시작한 뒤 완료 결과와 출력 폴더를 확인합니다.

### 공개 소스에서 실행하는 경우
Windows의 Python 환경에서 저장소 루트를 기준으로 다음과 같이 진행합니다.

```powershell
python -m pip install -r requirements.txt
python app_entry.py
```

Windows 빌드 환경을 준비한 개발자는 저장소의 `EXE_빌드.bat` 또는 `build_windows.py`를 사용할 수 있습니다.
